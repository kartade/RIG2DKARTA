# RIG2D

Éditeur web de rigging 2D généraliste.

## MVP

- Import et assemblage des calques PNG transparents
- Pivots, transformations et squelette articulé
- Timeline et images clés
- Sauvegarde locale et exports

Stack prévue : React, TypeScript, PixiJS, Zustand, Vite.

Ce dépôt hébergera le développement incrémental de RIG2D.
