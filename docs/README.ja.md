# RIG2DKARTA — 2Dリギング・アニメーションスタジオ

> レイヤー化された2Dキャラクターを組み立て、リギングしてアニメーションを制作するオープンソースのWebエディターです。

![Status](https://img.shields.io/badge/status-early%20prototype-orange) ![React](https://img.shields.io/badge/React-19-149eca) ![TypeScript](https://img.shields.io/badge/TypeScript-5-blue) ![PixiJS](https://img.shields.io/badge/PixiJS-8-purple)

## 概要

RIG2DKARTAはブラウザーで動作する**ローカルファースト**の2Dエディターです。透過PNGレイヤーを読み込み、キャラクターを組み立て、関節を設定し、タイムラインでアニメーションを制作できるツールを目指しています。将来的にはボーンリギング、メッシュ変形、表情、GIF・動画書き出しに対応する予定です。**これらの機能はまだすべて実装されているわけではありません。**

## インストール

### 必要環境
- 新しいNode.js（LTS推奨）
- npm
- WebGL対応のモダンブラウザー

### 起動
```bash
git clone https://github.com/kartade/RIG2DKARTA.git
cd RIG2DKARTA
npm install
npm run dev
```

Viteが表示するローカルURL（通常 `http://localhost:5173`）を開きます。

### 本番ビルド
```bash
npm run build
npm run preview
```

## プロトタイプの使い方

1. **Importer PNG** で透過PNGを複数選択します。
2. リストまたはキャンバス上でレイヤーを選択します。
3. ドラッグするか、**Propriétés** で座標を変更します。
4. 回転、スケール、ピボットを調整します。
5. レイヤーの順序や表示状態を変更します。
6. **Enregistrer** で `rig2d-project.json` を保存します。
7. **Ouvrir projet** でプロジェクトを再読込します。

現在のUIボタンはフランス語表記です。画像はJSONに埋め込まれるためファイルが大きくなる場合があります。将来的には素材を分離したZIP形式を検討しています。

**現在の技術構成：** React、TypeScript、Vite、PixiJS。Zustandは依存関係にありますが、まだ使用していません。

**目標とする構成：**
- **Editor UI：** パネル、操作ツール、インスペクター、タイムライン
- **Rigging Core：** ピボット、ボーン、階層、ローカル・グローバル変換
- **Animation Engine：** キーフレーム、補間、ループ、再現性のある再生
- **Renderer：** PixiJSによる描画と操作
- **Project I/O：** プロジェクトの読み込みと書き出し
- **Exporters：** PNG連番、GIF、将来的には動画

これは今後のリファクタリング方針であり、現時点のコード構造ではありません。

## 開発方針

- **ローカルファースト：** 編集にアカウントやサーバーは不要
- **汎用性：** キャラクター形式や画風を限定しない
- **非破壊編集：** 元画像と編集可能な変形を保持
- **可搬性：** 文書化された書き出し可能な形式を優先
- **拡張性：** アニメーションエンジンとUIを分離

## 検証用キャラクター

ちびキャラクターの**Néa**を最初のテストケースとし、PNGパーツの読み込み、基本ポーズの組み立て、ダンスアニメーションを試します。体型の異なる別のキャラクターでも汎用性を確認します。
