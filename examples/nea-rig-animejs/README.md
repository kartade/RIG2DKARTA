# Néa — animation articulée (référence)

Source : archive utilisateur `nea-rig-animejs(2).zip`.

Le ZIP contient un prototype HTML/Anime.js, un manifeste et **15 PNG transparents** (tête, torse, jupe, bras, avant-bras, mains, cuisses, tibias et bottes).

**État de l'import : partiel.** Le manifeste a été enregistré dans ce dossier. Le fichier `index.html` et les 15 PNG du ZIP **ne sont pas encore transférés dans GitHub**. Ce dossier n'est donc pas une démo exécutable pour l'instant.

L'archive d'origine reste la référence pour la reprise de l'import. Ne pas substituer des images recréées aux PNG fournis.

Le prototype d'origine se lançait via `python -m http.server 8000` et utilisait un cycle de danse de 24 poses interpolées à 100 ms, avec Anime.js v4 chargé via CDN pour l'animation secondaire.
